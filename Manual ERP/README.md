# Enterprise Multi-Tenant SaaS ERP (Dine-IIn / ERP)

Welcome to your brand-new, modern, and highly scalable **Enterprise Multi-Tenant SaaS ERP**! 

This system is built with a **Modular Monolith Architecture**—allowing rapid developer velocity while maintaining strict domain separation, making it trivial to split individual modules (CRM, HR, Finance) into dedicated microservices as your scale expands.

---

## 🛠️ Technology Stack & Core Decoupling

| Layer | Technology | Rationale |
| :--- | :--- | :--- |
| **Backend Framework** | **Node.js + Express + TypeScript** | High performance, modular controller-service separation, fast execution, and strict type safety. |
| **Database ORM** | **Prisma ORM** | Autogenerated type-safe query building, and fluid DB migrations. |
| **Multi-Tenancy** | **Logical Workspace Isolation** | Zero database leaks. All core models map strictly using `companyId` and `companyCode`. Ready to support Row-Level Security (RLS). |
| **Local Database** | **SQLite (Zero-Config local)** | Bootstrap instant dev workspaces without complex local PostgreSQL setup or credentials. Database is structured to swap to **PostgreSQL** by changing two lines. |
| **Realtime Engine** | **Socket.io (WebSockets)** | Delivers high-speed, instant in-app alerts directly into the employee's active dashboard. |
| **Frontend Framework** | **React + Vite 8 + TypeScript** | Hyper-fast build times, clean component composition, and responsive workflows. |
| **Styling Engine** | **Tailwind CSS v4 + Outfit/Inter fonts** | Sleek, modern dark-slate dashboard UI loaded with neon purple accent glows and interactive micro-animations. |

## ⚡ Quick Start: Zero-Config Startup

Ensure you have **Node.js (v24+)** installed on your Windows machine. Since standard global `npm` installations can occasionally suffer file corruptions, we utilize Node's built-in **Corepack** engine to run `pnpm` instantly with zero global permission locks.

### Step 1: Initialize Packages and Database
Open your terminal (PowerShell) and navigate to the project folders:

1. **Setup & Seed Database (Backend):**
   ```powershell
   cd backend
   # Install dependencies
   corepack pnpm install
   # Push our database schema and compile type-safe Prisma clients
   corepack pnpm prisma db push
   ```

2. **Setup Frontend:**
   ```powershell
   cd ../frontend
   # Install dependencies
   corepack pnpm install
   ```

---

### Step 2: Spin Up the Application

You will need to open **two terminal panels** to run the servers concurrently:

* **Terminal 1: Start the Backend server (Runs on port `5000`):**
  ```powershell
  cd backend
  corepack pnpm run dev
  ```
  *(You will see a confirmation console message saying that the server is running on `http://localhost:5000` and the SQLite database is active).*

* **Terminal 2: Start the React Frontend dashboard (Runs on port `5173`):**
  ```powershell
  cd frontend
  corepack pnpm run dev
  ```
  *(Hold `Ctrl` and click the `http://localhost:5173` link printed in the terminal to load the premium ERP panel in your web browser!)*

## 📱 Cross-Platform Packaging (Windows & Android)

Our ERP client dashboard is fully optimized to run as a native experience on both **Windows Desktop** and **Android Mobile** devices. Below are the standard wrappers and step-by-step commands to compile the web application into native binaries.

---

### 🪟 1. Windows Desktop Packaging (Tauri / Electron)

You can package the React frontend as a high-performance Windows desktop client using **Tauri** (recommended for tiny bundle sizes) or **Electron** (recommended for maximum legacy OS compatibility).

#### Option A: Packaging with Tauri (Recommended)
Tauri uses the system's native WebView2 engine, resulting in extremely lightweight (~10MB) `.exe` executables.

1. **Install Tauri CLI in the frontend directory:**
   ```powershell
   cd frontend
   corepack pnpm add -D @tauri-apps/cli
   ```
2. **Initialize Tauri project specifications:**
   ```powershell
   corepack pnpm tauri init
   ```
   * *When prompted, configure:*
     * **What is your app name?** `Manual ERP`
     * **What is the window title?** `Manual ERP Corporate Console`
     * **Where are your web assets (HTML/CSS/JS)?** `../dist` (points to Vite production output)
     * **What is the URL of your dev server?** `http://localhost:5173`
3. **Run the desktop console in Development Mode:**
   ```powershell
   corepack pnpm tauri dev
   ```
4. **Compile the production `.exe` installer:**
   ```powershell
   corepack pnpm tauri build
   ```
   *(The standalone installer will be available under `frontend/src-tauri/target/release/bundle/msi/` or `setup.exe`).*

#### Option B: Packaging with Electron
1. **Install Electron in the frontend:**
   ```powershell
   cd frontend
   corepack pnpm add -D electron electron-builder
   ```
2. **Configure an `electron-main.js` script** that points to `dist/index.html` or `http://localhost:5173`.
3. **Execute compilation:**
   ```powershell
   npx electron-builder --win
   ```

---

### 🤖 2. Android Mobile Integration (Capacitor wrapper)

We utilize **Capacitor** to wrap our React app output inside a native Android wrapper, exposing full native features (like localized push notifications, secure hardware keystores, and offline storage).

#### Step-by-Step Android Compilation:

1. **Install Capacitor Core and CLI inside the frontend directory:**
   ```powershell
   cd frontend
   corepack pnpm add @capacitor/core
   corepack pnpm add -D @capacitor/cli @capacitor/android
   ```

2. **Initialize the Capacitor Configuration:**
   ```powershell
   npx cap init "Manual ERP" "com.manualerp.app" --web-dir=dist
   ```

3. **Add the Android Native Project Folder:**
   ```powershell
   npx cap add android
   ```
   *(This creates a high-fidelity native Android studio project folder inside `frontend/android/`).*

4. **Build the production Vite distribution:**
   ```powershell
   corepack pnpm run build
   ```

5. **Synchronize/Copy web assets into the Android native envelope:**
   ```powershell
   npx cap sync
   ```

6. **Open the native project inside Android Studio to run on an Emulator/Device or compile `.apk`:**
   ```powershell
   npx cap open android
   ```
   *Within Android Studio:*
   * Click **Run** to launch the ERP instantly on your connected physical Android test device or Virtual Device emulator.
   * Click **Build > Build Bundle(s) / APK(s) > Build APK(s)** to export a standalone `.apk` installer ready for deployment!

## 📈 Scalability to Production (PostgreSQL & Microservices)

When you are ready to deploy to production:
1. **Swap to PostgreSQL:**
   * In `backend/prisma/schema.prisma`, change `provider = "sqlite"` to `provider = "postgresql"`.
   * In `backend/.env`, modify your `DATABASE_URL` to point to your live PostgreSQL cloud database.
   * Re-run `corepack pnpm prisma db push` to synchronize schemas.
2. **Microservices Migration:**
   * Because the controllers inside `backend/src/controllers/` are fully isolated by domain actions and communicate via standard service interfaces, you can easily rip out `HR`, `CRM`, or `Finance` into separate repositories, wrap them in Docker containers, and run them as fast microservices speaking over HTTP REST or gRPC!
