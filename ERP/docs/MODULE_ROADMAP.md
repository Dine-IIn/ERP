# Module Roadmap

## Foundation

- Auth and platform users
- Company provisioning
- Tenant database migrations
- RBAC and permission scopes
- Feature flags and licensing
- Audit logs

## ERP Core

- Inventory products, variants, warehouses, movements, reservations
- Sales quotations, sales orders, invoices, delivery notes, returns, credit notes
- Purchase requests, purchase orders, goods receipts, vendor invoices, purchase returns
- Manufacturing BOMs, production orders, stages, consumption, finished goods, scrap, machines, QC

## Collaboration

- Direct messages
- Group and department chat
- Mentions
- Attachments
- Tasks
- Work notes
- Expense groups
- Calendar

## Automation

- Approval workflow designer
- Multi-step approval execution
- Rule-based automation triggers
- Scheduled actions
- Email and notification automation

## Operations

- Backup scheduling
- Restore workflows
- Retention policies
- Report generation
- PDF, Excel, and CSV exports
